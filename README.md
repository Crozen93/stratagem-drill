# Stratagem Drill — мини-игра для Galaxy Watch 7

Тренажёр кодов-стратагем в чёрно-жёлтом военном стиле. Вверху появляется стратагема, и нужно успеть ввести её код свайпами, пока не кончилось время.

## Управление

- **Свайп вверх / вниз / влево / вправо** вводит стрелку. Свайп засчитывается сразу, отпускать палец не нужно.
- Ошибка сбрасывает текущий код и отменяет бонус «Без ошибок».
- Каждая введённая стратагема добавляет времени. С каждым раундом стратагем больше, коды длиннее, а добавка времени меньше.
- **Долгое нажатие на титульном экране** включает или выключает звук. Громкость регулируется кнопками громкости медиа.
- **Выход** — кнопкой «Назад» на часах. Свайп вправо закрывать игру не будет, потому что это стрелка.

## Сборка через GitHub

1. Создай новый репозиторий и загрузи в него содержимое этой папки, включая скрытую папку `.github`.
2. Открой вкладку **Actions**. Сборка «Build APK» запустится сама, это около 3–4 минут.
3. Открой готовый запуск и скачай артефакт **stratagem-drill-apk**. Внутри `app-debug.apk`.
4. Установи на часы по Wi-Fi так же, как основное приложение:
   ```
   adb connect IP:ПОРТ
   adb install app-debug.apk
   ```

## Как поменять стратагемы

Список лежит в `app/src/main/java/com/crozen/stratagemdrill/Stratagem.java`, массив `ALL`. Код записывается буквами `U D L R`, максимум 8 стрелок. Иконка выбирается из готовых типов (`STRIKE`, `SUPPLY`, `TURRET` и т. д.), цвет — `RED`, `BLUE`, `GREEN` или `YELLOW`.

## Устройство

- `Game.java` — правила, раунды, таймер, очки.
- `GameView.java` — отрисовка на Canvas и свайпы.
- `Icons.java` — иконки, нарисованные кодом.
- `Sfx.java` — звуки синтезируются в коде при запуске, плюс вибрация.

Внешних библиотек нет, только Android SDK. Минимальная версия — Wear OS 3 (API 30).
